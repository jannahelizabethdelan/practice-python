# practice-python

Practice exercises for learning Python fundamentals, one exercise per file.
Each exercise is developed on its own branch and merged through a pull request.

## Exercises

- [ ] 01_variables_basics — variables & types
- [ ] 02_variables_fstrings — f-strings & type casting
- [ ] 03_conditions_basic — if / elif / else
- [ ] 04_conditions_logic — comparison & logical operators
- [ ] 05_loops_for — for loop / range
- [ ] 06_loops_while — while loop
- [ ] 07_functions_basic — function with return
- [ ] 08_functions_args — default args, multiple returns
- [ ] 09_lists_basic — list operations
- [ ] 10_lists_comprehension — list comprehension
- [ ] 11_dicts_basic — dictionary operations
- [ ] 12_dicts_iterate — iterating a dictionary
- [ ] 13_files_write — writing/reading text files
- [ ] 14_files_lines — appending, reading line by line
- [ ] 15_errors_tryexcept — try / except

## How to run

Each exercise is a standalone script:

python 01_variables_basics.py

## Workflow

Each exercise is built on its own branch and merged into main through a
pull request, following a standard feature-branch workflow.
